# Asset fidelity and production assets

All nine user-supplied refined employer PNGs were compared with their original uploads. The refinements altered trademark details, so the original supplied artwork is used under the brief's fidelity rule. Original/refined comparisons are retained in the owner's local project package rather than this public repository.

Production artwork is stored in public/logos/ with its original colours, wording and proportions. No corporate mark was redrawn, recoloured, stretched or cropped. Some originals have source padding or limited resolution; verified high-resolution official artwork would improve those marks.
